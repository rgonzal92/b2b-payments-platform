# PostgreSQL as the primary database

The job posting this project mirrors names MySQL, DB2 and Oracle; we use PostgreSQL anyway. It is already familiar, so the project's learning time goes to the runtime technologies that are new (WebFlux, gRPC, Spring Batch, JMS) rather than to a new database. PostgreSQL still exercises the SQL depth the posting asks for: window functions, partitioning, `SKIP LOCKED` work queues, and logical replication for change data capture.

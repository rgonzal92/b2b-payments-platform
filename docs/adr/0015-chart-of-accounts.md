# Four Accounts in the double-entry journal

The journal starts with four kinds of Account: a Buyer Receivable per Buyer, one Network Settlement Payable, one Issuer Cash and one Clearing Suspense. A Clearing debits the card's Buyer Receivable and credits the Network Settlement Payable; a Settlement debits the Network Settlement Payable and credits Issuer Cash; a Repayment debits Issuer Cash and credits the Buyer Receivable; a Clearing whose card can't be identified debits Clearing Suspense instead, so the file still balances. Every Journal Entry balances, is never changed or deleted, and carries an idempotency key (the Network record ID for a Clearing).

Available Credit becomes the Credit Line minus the Buyer Receivable balance minus open Holds, so cleared spend is read from the journal rather than kept as a separate counter. We chose a real double-entry journal over a single "posted spend" column per Buyer because it is how an Issuer's books work, every movement is traceable to the entry that caused it, and the M4 Reconciliation can prove the books balance; the cost is that changing the chart later means migrating entries, so new Accounts are added rather than existing ones reshaped.
